Administración del Observatorio

Área protegida por Spring Security. Los cambios de datos se realizan desde Supabase, para evitar escrituras públicas o importaciones accidentales.

Datos y fuentes

Denuncias: SIDPOL 2022–2025. Homicidios: INEI/CEIC 2022–2024 y estimación preliminar nacional 2025.

Para actualizar registros: Supabase → Table Editor → Import data from CSV. Consulta la guía adjunta.

Accesos

Solo ADMIN puede acceder a esta página. El público puede consultar el dashboard sin autenticarse.

Configura ADMIN_USERNAME y ADMIN_PASSWORD en Render. Nunca publiques la contraseña en GitHub.
